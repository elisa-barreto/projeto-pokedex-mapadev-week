# Pokedex Project - Dev Quest

This project was developed during the Dev Quest front-end course and consists of an interactive web page with a Pokémon theme. The main objective was to apply the knowledge acquired in HTML, CSS, and JavaScript to create a dynamic Pokémon character viewing experience.

## Overview

Upon accessing the page, the user sees a set of static cards displaying various Pokémon characters. Through control buttons, it is possible to navigate and display a single character in focus at a time, providing an individual exploration of each Pokémon.

## Technologies Used

* **HTML:** Page structure and element organization.
* **CSS:** Essential for the **complete visual styling of the page**, including colors, typography, sizes, spacing, and responsive layout. The use of **Flexbox** was fundamental for the efficient alignment and distribution of elements, both in the initial arrangement of the cards and in controlling the display of the single character, ensuring adaptability to different screen sizes.
* **JavaScript:** Implementation of interactivity, navigation logic between characters, DOM manipulation to display the current character, and control of button visibility.

## Main Concepts Addressed

* **Structure with Divs:** The page was structured using `<div>` to organize the content into logical sections and facilitate the application of styles and manipulation with JavaScript.
* **Layout with Flexbox:** CSS Flexbox was extensively used to create flexible and responsive layouts, both in the initial arrangement of the cards and in controlling the display of the single character. This allowed for efficient alignment and adaptability to different screen sizes.
* **Styling with CSS:** CSS played a crucial role in the **visual presentation of the project**, defining the appearance of the Pokémon cards, navigation buttons, page background, and other elements. Through CSS, it was possible to create an attractive interface aligned with the Pokémon theme.
* **Interactivity with JavaScript:** The page's interactivity is managed by JavaScript, which captures click events on the "Next" and "Previous" buttons. The implemented logic allows for:
    * Controlling the index of the currently displayed character.
    * Manipulating the DOM to show the corresponding character card and hide the others.
    * (Implicitly) Dynamically updating the visual interface.
* **Conditional Display:** JavaScript controls which character card is visible on the screen, showing only one at a time after interaction with the buttons.
* **Publication with GitHub Pages:** The project has been hosted and is accessible via GitHub Pages at [https://elisa-barreto.github.io/projeto-pokedex-mapadev-week/](https://elisa-barreto.github.io/projeto-pokedex-mapadev-week/).

## Demonstration

This project demonstrates the practical application of fundamental front-end concepts learned in the Dev Quest course, focusing on structuring with divs, the power of layout with Flexbox, the **importance of CSS for styling**, and creating interactivity with JavaScript.

# Projeto Pokedex - Dev Quest

Este projeto foi desenvolvido durante o curso de front-end Dev Quest e consiste em uma página web interativa com tema Pokémon. O objetivo principal foi aplicar os conhecimentos adquiridos em HTML, CSS e JavaScript para criar uma experiência dinâmica de visualização de personagens Pokémon.

## Visão Geral

Ao acessar a página, o usuário visualiza um conjunto de cartões estáticos exibindo diversos personagens Pokémon. Através de botões de controle, é possível navegar e exibir um único personagem em destaque por vez, proporcionando uma exploração individual de cada Pokémon.

## Tecnologias Utilizadas

* **HTML:** Estrutura da página e organização dos elementos.
* **CSS:** Essencial para a **estilização visual completa da página**, incluindo cores, tipografia, tamanhos, espaçamentos e o layout responsivo. O uso de **Flexbox** foi fundamental para o alinhamento e a distribuição eficiente dos elementos, tanto na disposição inicial dos cartões quanto no controle da exibição do personagem único, garantindo a adaptabilidade a diferentes tamanhos de tela.
* **JavaScript:** Implementação da interatividade, lógica de navegação entre os personagens, manipulação do DOM para exibir o personagem atual e controle da visibilidade dos botões.

## Principais Conceitos Abordados

* **Estrutura com Divs:** A página foi estruturada utilizando `<div>` para organizar o conteúdo em seções lógicas e facilitar a aplicação de estilos e a manipulação com JavaScript.
* **Layout com Flexbox:** O CSS Flexbox foi amplamente utilizado para criar layouts flexíveis e responsivos, tanto na disposição inicial dos cartões quanto no controle da exibição do personagem único. Isso permitiu um alinhamento eficiente e adaptabilidade a diferentes tamanhos de tela.
* **Estilização com CSS:** O CSS desempenhou um papel crucial na **apresentação visual do projeto**, definindo a aparência dos cartões dos Pokémon, dos botões de navegação, do fundo da página e de outros elementos. Através do CSS, foi possível criar uma interface atraente e alinhada ao tema Pokémon.
* **Interatividade com JavaScript:** A interatividade da página é gerenciada pelo JavaScript, que captura os eventos de clique na listagem de botões. A lógica implementada permite:
    * Controlar o índice do personagem atualmente exibido.
    * Manipular o DOM para mostrar o cartão do personagem correspondente e esconder os demais.
    * (Implícito) Atualizar a interface visual dinamicamente.
* **Exibição Condicional:** O JavaScript controla qual cartão de personagem está visível na tela, mostrando apenas um por vez após a interação com os botões.
* **Publicação com GitHub Pages:** O projeto foi hospedado e está acessível através do GitHub Pages em [https://elisa-barreto.github.io/projeto-pokedex-mapadev-week/](https://elisa-barreto.github.io/projeto-pokedex-mapadev-week/).

## Demonstração

Este projeto demonstra a aplicação prática dos conceitos fundamentais de front-end aprendidos no curso Dev Quest, com foco na estruturação com divs, no poder do layout com Flexbox, na **importância do CSS para a estilização** e na criação de interatividade com JavaScript.
